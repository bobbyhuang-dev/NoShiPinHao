# NoShiPinHao (去除视频号)

[中文](README.md)

A macOS app that removes Channels (视频号) and other distracting features from WeChat for Mac.

The WeChat mobile app lets you turn off Channels, but the Mac app has no such option. This tool fills that gap.

The app and most documentation are in Simplified Chinese. See the [Chinese README](README.md) for build commands and project layout.
